CAKE CHÁVEZ — PAQUETE CORREGIDO PARA GITHUB PAGES

QUÉ INCLUYE
- Navidad como única temática incluida y activa inicialmente.
- Panel avanzado > Temáticas > Agregar tema.
- Instalación de ZIP con análisis y vista previa antes de publicar.
- Botones Vista previa, Cambiar, Actualizar tema, Historial/Restaurar y Eliminar.
- Ingreso de administración con correo y contraseña, sin verificación de dispositivo.
- Las demás temáticas NO están instaladas: cada una se agrega con su ZIP por separado.

1. PUBLICAR EN GITHUB
Sube a la raíz de tu repositorio el CONTENIDO de la carpeta cake-chavez (index.html debe quedar en la raíz). En GitHub abre Settings > Pages, elige Deploy from a branch, tu rama principal y /(root). Guarda.

2. PREPARAR LA BASE (UNA SOLA VEZ)
Haz primero una copia de seguridad. En tu Supabase abre SQL Editor y ejecuta 01_tematicas_zip.sql completo. Es aditivo: no borra pedidos, productos, cuentas ni Navidad. No ejecutes eliminar_control_dispositivos.sql salvo que todavía tengas esa tabla antigua y quieras retirarla; primero lee su bloque de revisión.

3. CREAR EL ESPACIO PARA LOS RECURSOS
En Storage crea un bucket llamado exactamente: cake-theme-assets
- Debe ser PÚBLICO para que GitHub Pages pueda mostrar las imágenes, CSS, música y videos de las temáticas (no contiene fotos privadas de clientes).
- Límite recomendado: 30 MB por archivo.
- El SQL permite subir o borrar únicamente con una sesión de administradora y cada subida queda ligada a su usuario. Los visitantes no pueden subir ni listar archivos.

4. AGREGAR O ACTUALIZAR UNA TEMÁTICA
Entra a admin.html con tu correo y contraseña. Abre Panel avanzado > Temáticas.
- Agregar tema: elige el ZIP, espera el análisis, revisa el contenido y pulsa Instalar temática.
- Instalar NO cambia la tienda automáticamente. Usa Vista previa y, cuando esté lista, Cambiar a esta temática.
- Actualizar tema: sube otra versión del ZIP de esa misma temática.
- Historial: permite restaurar una versión anterior como una versión nueva.
- Eliminar: conserva los enlaces antiguos y devuelve la tienda a Navidad si esa temática estaba activa. Navidad no se puede eliminar.

5. COMPROBAR
Abre la tienda y confirma Navidad. Después entra al panel y confirma que aparecen Agregar tema y, en la tarjeta de Navidad, Vista previa, Actualizar tema e Historial. Instala primero un ZIP de prueba o una temática que quieras usar; no hace falta subir las demás al repositorio.

Nota: el archivo supabase-config.js conserva la conexión del paquete anterior. No contiene la clave privada service_role y no debes agregarla a GitHub.
