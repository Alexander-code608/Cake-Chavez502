Configura la conexión segura

Antes de usar este panel, completa supabase-config.js con la URL del proyecto y la clave pública de Supabase. Sigue el archivo README.md y las instrucciones de documentacion/INSTALACION_Y_PRUEBAS.md. Nunca pongas la clave service_role en el navegador.

No ejecutes archivos SQL de otros proyectos. Antes de ejecutar una migración, confirma que corresponde a tu base de datos actual.
